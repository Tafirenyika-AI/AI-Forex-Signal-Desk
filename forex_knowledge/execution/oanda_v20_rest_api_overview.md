# OANDA v20 REST API Overview

## Core Description

The OANDA v20 REST API enables programmatic access to OANDA's trading engine. According to the documentation, it "provides programmatic access to OANDA's next generation v20 trading engine" and requires a v20 trading account (unavailable to certain divisions).

## API Structure

The system organizes functionality through six primary endpoint categories:
- Account management
- Order operations
- Trade management
- Position handling
- Transaction records
- Pricing data

Supporting definitions cover Accounts, Instruments, Orders, Trades, Positions, Transactions, Pricing, and Primitives.

## Key Capabilities

**Market Data Access:**
The API allows users to "Get real-time rates for all tradeable pairs 24 hours a day" and "Access historical pricing information dating back to 2005."

**Trading Operations:**
Capabilities include placing, modifying, and closing orders; managing account settings; and accessing account and trading history.

## Getting Started Steps

The documentation outlines three primary steps: obtaining a v20 fxTrade account, acquiring REST API access through the Account Management Portal (generating a personal access token), and beginning automated trading requests using that token.
